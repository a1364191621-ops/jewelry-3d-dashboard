    欢迎来逛，慢慢挑选。

    实景模式：在门头点击「进入店铺」，视角推进后进入店内全景；点击「继续逛店」游览店内视点，「返回门外」回到门头。也可以点击底部缩略图切换 7 张照片，点击数字光点查看商品。

    3D 模式：按住鼠标拖动旋转视角，W 前进、S 后退、A 左移、D 右移。手机拖动看向，长按方向键移动。「重置视角」返回当前商品组入口。

    图片与 index.html 放在同一文件夹，无需本地服务器。实景图为普通实拍照片；自由漫游位于独立的 3D 商品展厅。

    导入 JSON 可替换当前商品库，统计和热销排名自动更新。支持数组或包含 products 数组的对象：

    {
  "products": [
    {
      "id": "MM-01",
      "name": "珍珠叠戴项链",
      "category": "项链",
      "price": 168,
      "stock": 12,
      "sales": 32,
      "image": "necklace.jpg",
      "description": "温柔珠光，适合日常搭配。"
    }
  ]
}

    必填：id、name、price、stock、sales。价格为非负数字，最多两位小数；库存和销量为非负整数。category、description（也可用 desc）、image 可省略。

    商品编号 MM-01 至 MM-15 对应固定的 15 个实景热点。保留编号即可更新该热点；导入文件未包含的编号会显示「商品未关联」，不会误用其他商品。新增编号仍可在 3D 展厅浏览。

    image 填同文件夹中的图片文件名，也支持 HTTP/HTTPS 图片地址。省略时，已知编号沿用实拍陈列裁切视图；其他商品显示陈列参考图。本页不使用内嵌编码图片。

    文件仅由浏览器读取，刷新恢复示例资料。单文件最多 5 MB、1,000 款商品。空数组可清空商品库。导入失败时保留当前数据。

    展厅使用原生 CSS 3D 与 JavaScript，无需安装依赖或加载 CDN。所有店铺照片均为本地外部文件。初始名称、价格、库存、销量和新增视点的热点位置为示例，请根据实际商品核对。
